# 🧠 TotalRecall

React flashcards for studying programming. Decks cover the terms you meet when learning web development, and spaced repetition brings each card back right before you'd forget it.

**Status:** in planning. Code is on the way.

## Planned features

- Decks of programming terms: HTML, CSS, JavaScript, React, Python, SQL and more
- A short code example on the back of every card
- Spaced repetition that schedules each card by how well you knew it
- Keyboard-only study and screen-reader friendly cards
- Import and export decks as JSON to share them
- Progress and streaks saved in the browser

## Built with

React, JavaScript, esbuild, Node's test runner, GitHub Pages
